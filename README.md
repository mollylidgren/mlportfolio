# Portfolio v.3.1

React + TypeScript + Vite + Tailwind CSS portfolio.

## Homepage polish in v3.1
- Active navigation uses a sharp pink underline instead of a soft pink box.
- Hero project cards transition more smoothly with deeper 3D rotation and slower easing.
- Capability cards use a compact three-column desktop layout with a solid glass hover panel so text stays readable over the visual.
- Homepage spacing around the capability section is tighter.
- Mobile hero copy uses a dark glass/pink treatment for stronger contrast over the project imagery.
- Footer includes placeholder email/contact information and navigation links.

## Run
```bash
nvm use 22
npm install
npm run dev
```
